# ليالي | LAYALI

منصة دعوات زفاف عربية متصلة بمشروع Supabase `gxredstctzkuwgsegykd`.

## روابط
- `index.html`: معاينة سينمائية؛ الدعوة المنشورة تعمل عبر `index.html?invite=SLUG`.
- `dashboard.html`: تسجيل دخول وإنشاء حساب، إدارة مسودات الدعوات، مشاهدة الردود، وتفعيل الدعوات من حساب المدير.
- `studio.html`: أداة معاينة محلية قديمة، ليست نظام النشر.
- فيديو الأبواب: `kling_20261106_VIDEO_Ultra_phot_5867_0_1.mp4`.

## قاعدة البيانات
تم إنشاء جدولي `public.layali_invitations` و`public.layali_rsvps` مع RLS وفهارس. الحساب العادي ينشئ ويعدل مسوداته فقط. المدير يستطيع نشر وإيقاف الدعوات. `layali-public` Edge Function تعرض الدعوات المنشورة فقط وتستقبل RSVP.

## إعداد المدير
1. أنشئ حساباً عبر `dashboard.html` وأكّد البريد إذا طُلب.
2. من Supabase Auth Admin API على خادم آمن، امنح المستخدم `app_metadata.role = "layali_admin"`. لا تستخدم `user_metadata` ولا تكشف مفتاح `service_role` في الواجهة.
3. سجّل خروجاً ودخولاً لتجديد JWT؛ ستظهر أدوات المدير.
4. أنشئ الدعوة كمسودة، ثم انشرها من حساب المدير بعد تأكيد الدفع.
5. شارك رابط `index.html?invite=SLUG` مع الضيوف.

## أمور متبقية قبل الإطلاق التجاري
- إعداد SMTP وروابط تأكيد البريد، حماية كلمات المرور المسرّبة، CAPTCHA وrate limiting أكثر قوة على RSVP.
- اختبار المتصفحات والموبايل، ومراقبة الأخطاء والنسخ الاحتياطي.
- القوالب الستة حالياً ألوان مختلفة، وليست ست تجارب مصممة مستقلة.
- لا يوجد حتى الآن ظرف ثلاثي الأبعاد أو موسيقى مرخصة أو لوحة فواتير/مدفوعات.
- المعاينة العامة بدون `invite` لا تحفظ RSVP فعلياً.

## الأمن
مفتاح Supabase `sb_publishable_` الظاهر في المتصفح عام ومسموح. مفتاح `service_role` محفوظ في بيئة Edge Functions. لا توجد عمليات حذف لبيانات سابقة؛ كان مخطط `public` فارغاً عند الفحص.
