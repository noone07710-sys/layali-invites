# ليالي — Layali Invitations

نموذج أولي تفاعلي لمنصة بيع دعوات زفاف إلكترونية باللغة العربية.

## التجربة
افتح `index.html` في المتصفح. توجد صفحة رئيسية وستة قوالب ولوحة مدير تجريبية ومحرر زبون ومعاينة دعوة وRSVP.

## تنبيه مهم
هذه **نسخة عرض Frontend Prototype فقط**. تخزين البيانات عبر localStorage داخل المتصفح، وليس قاعدة بيانات مشتركة. روابط التفعيل ليست آمنة ولا تعمل بين الأجهزة بالشكل التجاري المطلوب. لا توجد مصادقة أو صلاحيات خادمية أو نشر فعلي للدعوات. لا تستخدمها مع زبائن حقيقيين.

## خطة الإنتاج
- Next.js + TypeScript + Tailwind CSS + Motion.
- Supabase Auth لتسجيل دخول المدير والزبائن، مع Row Level Security على جداول العملاء والدعوات والضيوف.
- جداول `profiles`, `activations`, `invitations`, `rsvp_responses`, `templates`, `audit_logs`.
- رموز تفعيل عشوائية تخزن مجزأة، صالحة للاستخدام مرة واحدة، مع جلسة مصادق عليها بعد الاسترداد.
- فصل بيانات الدعوة عن القالب، ودعم ستة قوالب لكل عميل.
- حفظ وسائط القوالب والصور في Supabase Storage بسياسات وصول واضحة.
- رابط دعوة عام slug مستقل عن لوحة تعديل الزبون.
- نشر Vercel وربط نطاق واختبار أمان ومراقبة وإجراءات نسخ احتياطي.
